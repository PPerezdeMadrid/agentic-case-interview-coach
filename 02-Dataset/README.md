# 02-Dataset

This folder contains working materials and artefacts used to build the project's dataset. These include:

- case inventories and rubrics
- processed data and metadata
- extraction, cleaning, and review scripts
- supporting diagrams for the database structure

Version-control and provenance notes:

- The `eacl23_soqg/` folder should not be committed to this repository. It comes from an external GitHub repository, `NUS-IDS/eacl23_soqg`, which is the official repository for the SocratiQ dataset associated with the paper *Socratic Question Generation: A Novel Dataset, Models, and Evaluation*. Reference: https://github.com/NUS-IDS/eacl23_soqg
- The PDF files in this folder should not be committed to git either. They are used as source material and consulting casebooks for building or cross-checking cases.
- The reference source for the consulting cases collected in this folder is Career in Consulting's *280 Free Case Interview Examples* page: https://careerinconsulting.com/case-interview-examples/#elementor-toc__heading-anchor-11
