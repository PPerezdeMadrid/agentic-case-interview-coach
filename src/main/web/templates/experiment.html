Pooled across every dimension & scenario — each 1–4 score treated as a class

MAE, Recall, Precision & QWK

Recall for class n: of every case the reference truly scored n, how often this graph's judge also said n. Precision for class n: of every case this graph's judge scored n, how often the reference agreed. Both are macro-averaged (unweighted mean across classes) so a judge that only ever predicts the majority class (e.g. always 4) is penalized here even while pooled MAE still looks fine.

{% for s in overview.classification.summary %} {% endfor %}
Graph MAE Macro recall Macro precision Macro F1 QWK Compared
{{ s.graph_name }} {{ num(s.mae) }} {{ pct(s.macro_recall) }} {{ pct(s.macro_precision) }} {{ pct(s.macro_f1) }} {{ num(s.qwk) }} {{ s.n_compared }}
  • MAE — average point gap vs. the reference. Simple, but a judge that just guesses the majority class (mostly 3s/4s) can score a low MAE without discriminating good from bad performance.
  • Recall / Precision — per-class (1–4) accuracy, so a judge that never predicts the low classes is penalized here even when its MAE looks fine.
  • QWK (Quadratic Weighted Kappa) — the standard ordinal-agreement metric in the literature (essay scoring, clinical severity grading); corrects for the agreement expected by chance given the skewed reference distribution. 1.0 = perfect agreement, 0 = chance/majority-guessing level, negative = worse than chance. The most defensible single number for a thesis methodology section, since MAE alone can't tell "genuinely accurate" from "lucky because most cases are easy 3s/4s."

Does the judge know when to abstain?

Some scenarios don't exercise every rubric dimension (e.g. no standalone creative prompt) — the scenario author marks the reference score not_tested for those. This shows how often each graph's judge scored the dimension with a real number anyway, instead of recognizing it doesn't apply.
