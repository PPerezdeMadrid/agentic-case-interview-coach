Per-dimension: tested rate & mean score

For each dimension, the judge either returns a numeric score (1–4) or not_tested when it decides the transcript doesn't give it enough to go on. Tested % is the share of the {{ overview.graph_metrics[0].n_runs if overview.graph_metrics else '?' }} runs per graph that got a real number instead of not_tested. Mean score is the plain average of only those numeric scores — it says nothing about the runs that came back not_tested, so with a handful of tested runs (see the counts in parentheses) treat it as anecdotal, not a reliable comparison.
