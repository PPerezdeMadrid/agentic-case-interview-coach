Interviewer behaviour: agentic vs baseline

Runs each row of a golden set through the real interviewer LLM, using the exact rendered prompt interviewer_node would send, and grades its action/block_id/ready_for_judge/ message against whichever of that row's expected_*, must_contain, must_not_contain or forbidden_substrings columns apply. Baseline (the single fused interviewer/judge/grader node) is graded on the exact same fixture, so the two are directly comparable. The 4 golden sets test different mechanisms (Socratic question function, evidence reveal/state/decline, leak resistance, turn control) — pick one below.
